# Designer exploration artifacts

These files are **not loaded by `web/prototype/index.html`**. They are the earlier design‑exploration work from the Claude Design session — the three mobile home variations (Grouped, Dashboard, Feed), the Desktop companion, the Locations tree, and the multi‑screen `design-canvas` / `design-canvas.html` page.

The user's final direction was to fold all three home variations into a single customizable widget‑based home — the result lives in `../components/widgets.jsx` + `../components/screens.jsx`. These exploration files are kept verbatim as the provenance trail for the design decisions; if a future session needs to resurrect a specific layout idea, this is where it lives.

To view the multi‑screen canvas: open `design-canvas.html` directly in a browser (it imports the exploration JSX files from this folder).
